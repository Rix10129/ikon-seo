== Installation ==

1. Upload and activate the plugin.
2. Complete Ikon SEO → Website Profile.
3. Complete Ikon SEO → Website Strategy and choose the correct operating mode.
4. Open Ikon SEO → Local Growth and run the first evidence refresh.
5. Open Ikon SEO → Workflow Automation and create the recommended workflow.
6. Open Ikon SEO → Publisher Intelligence and configure opportunities, contributors and topic hubs.
7. Open Page Diagnostics and run the first evidence crawl.
8. Open Technical Intelligence and refresh URL discovery and the link graph.
9. Optionally connect Search Console and refresh Search Intelligence.
10. Open Content Intelligence and store current competitor observations for priority queries.
11. Build evidence-based briefs for important service pages and articles.
12. Optionally connect Google Analytics for behavioural and conversion evidence.
13. Review Site Inventory, Local SEO and Page Plans.
14. Choose whether a Google Business Profile is available.
15. Connect a private workspace only when you want assisted research or draft creation.

== Frequently Asked Questions ==

= Is AccountingService used on every website? =

No. It is available only when the active profile is an accounting business. Other industries receive their own curated schema policy.

= Can I move the plugin to another website? =

Yes. Install the same plugin and create or import a separate profile. Connection keys are never exported.

= Does it publish automatically? =

Draft-only mode is enabled by default. Improvement mode always creates a separate review draft.

= Does the CSV queue write hundreds of pages automatically? =

No. It stores approved page plans. A connected workflow must research and return each complete page while the private operator workspace is active. Every page still passes the normal checks and becomes a draft.

= Do I need a workflow connection to use the plugin? =

No. Website scans, audits, Local SEO, profiles, Page Plans and monitoring run locally in WordPress. Connected draft creation requires a separately configured compatible workflow; the plugin does not include a built-in content generation service.

= Can Ikon SEO request Google indexing? =

No. Search Console access is read-only. URL Inspection reports the indexed version known to Google; it does not request indexing or guarantee inclusion.

= Can it update a live page safely? =

An administrator can compare and merge an approved improvement into the original page while preserving its page ID and URL. A rollback snapshot is created first.

= Does a service-area page receive a LocalBusiness address? =

No. Only an active, verified storefront or hybrid location can generate a location entity and address. A service area records the places served without pretending that an office exists there.

= Can it post or answer reviews automatically? =

No. The connected workflow can prepare a draft, but only a WordPress administrator can approve the exact saved text. Remote approval, automatic replies and unattended Google Posts are not provided.

= Is Google Business Profile access truly read-only? =

Google provides the broad `business.manage` OAuth permission. Ikon SEO enforces a read-only operating mode inside the plugin and uses that permission for a write only after a WordPress administrator approves an exact saved draft.


= Is the fix priority a Google ranking score? =

No. It is an internal prioritisation score based on available evidence. Ikon SEO separates confirmed technical facts from inferred opportunities and does not claim access to Google's private ranking logic.

= Does Google Analytics change the website? =

No. The Analytics connection is read-only and is used only to add landing-page, engagement and key-event evidence to diagnostics.

= Do I need Google Analytics? =

No. Page crawling, WordPress evidence and local audits work without it. Analytics improves behavioural and conversion context when a GA4 property is available.


= Does Ikon SEO scrape Google or copy competitor pages? =

No. Competitor observations must come from current manual research, an approved connected workflow or a licensed provider. The plugin stores short factual evidence and compares recurring patterns. It does not copy competitor content or treat competitor claims as facts about the connected business.

= Is a recurring competitor topic automatically required? =

No. Frequency is evidence of a possible expectation, not a ranking factor. Every topic, entity and proof element must be checked for factual relevance, search intent and genuine usefulness before it is added.


= Does one strategy fit every website? =

No. Local businesses, editorial publishers, ecommerce stores and hybrid websites use different priorities, conversions, evidence and quality requirements. The active operating mode guides diagnosis and planning without changing live content automatically.

= Can the private workspace change the strategy? =

It can read the strategy with an empty request. A change is saved only when the request explicitly sets save to true and the connection key includes draft access. Agency administrators can also edit it in WordPress.


= Does Publisher Intelligence publish content automatically? =

No. It plans opportunities, stores assignments, runs quality gates and prepares lifecycle recommendations. Publishing, consolidation, retirement and redirects remain human-approved actions.

= How does portfolio duplication protection work? =

It exports hashed content signatures and short topic terms rather than full article text. The comparison is a warning system, not a plagiarism verdict, and every finding requires editorial review.


= Is Local Growth a local ranking score? =

No. It measures whether important local evidence and workflows are configured and maintained. Local results also depend on relevance, distance and prominence, and distance cannot be controlled by the plugin.

= Does Local Growth answer reviews or edit the Business Profile automatically? =

No. It can synchronize review status and prepare workflow tasks. Any reply or public profile change must be staged and explicitly approved by a WordPress administrator.

= Does Local Growth create a page for every service area? =

No. It warns against doorway-style area pages. A local page should be considered only when there is a genuine service relationship, a distinct user need and enough real local evidence to make the page useful.

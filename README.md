# Ikon SEO

Private source repository for the Ikon SEO WordPress plugin.

## Current release

- Version: **0.6.0**
- Workflow: **Profile → Connect → Scan → Create Draft**
- Safety: draft-only page creation; live publishing is disabled by default
- Integrations: Elementor and Rank Math

## Repository setup status

The repository has been created successfully. The plugin source files still need to be uploaded through GitHub’s web uploader.

### Easy upload — no Terminal required

1. Download and unzip `ikon-seo-v0.6.0.zip`.
2. Open the extracted `ikon-seo` folder.
3. In this GitHub repository, choose **Add file → Upload files**.
4. Select everything inside the extracted folder and drag it onto the GitHub upload page.
5. Enter `Upload Ikon SEO v0.6.0` as the commit message.
6. Choose **Commit directly to the main branch**, then click **Commit changes**.

## Important

Keep this repository private because it contains the complete plugin source code.

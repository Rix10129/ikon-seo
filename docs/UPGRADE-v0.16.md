# Upgrade to Ikon SEO v0.16.0

1. Back up the WordPress files and database.
2. Upload the v0.16.0 ZIP and choose **Replace current with uploaded**.
3. Open **Ikon SEO → Agency Access** and confirm the correct agency administrators.
4. Open **Ikon SEO → Publisher Intelligence**.
5. Add a small test opportunity, contributor profile and topic hub.
6. Create one pipeline item linked to an existing draft and run its quality gate.
7. Export a portfolio signature bundle and confirm that it contains signatures rather than full article text.
8. Re-import the focused action schema if a private workspace is connected.

Existing profiles, strategy, workflows, Search Console, Analytics, evidence, research, Page Plans, Project History and drafts are preserved.

# Diagnostic Accuracy

Ikon SEO 0.9.1 replaces generic checklist scoring with evidence-aware prioritisation.

## What changed

- SEO titles and descriptions are reviewed for presence, clarity and output rather than fixed character ranges.
- Content is assessed for availability and completeness rather than an assumed preferred word count.
- Focus topics are optional and use semantic token overlap rather than exact-match wording.
- Multiple H1 elements are not treated as an automatic ranking failure; a missing clear main heading remains a structural finding.
- Related symptoms are grouped by root cause to avoid scoring the same underlying problem repeatedly.
- Ranking blockers are separated from search-appearance opportunities, conversion issues, measurement gaps, experience and accessibility findings.

## Priority method

Each finding receives a work priority based on:

1. Likely impact
2. Evidence confidence
3. Page business value
4. Estimated implementation effort
5. Finding category

The page report then displays separate priorities for ranking, search growth, conversion, measurement and other experience work.

These priorities are workflow tools. They are not Google ranking scores and do not guarantee a position change.

## Evidence sufficiency

Every page receives an evidence-sufficiency level based on the sources currently available:

- WordPress inventory
- Same-site crawl
- Search Console
- Google Analytics
- URL Inspection

Inferred recommendations should be treated more cautiously when evidence is limited or developing.

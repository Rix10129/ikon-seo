# Upgrade to Ikon SEO 0.11.0

1. Upload the 0.11.0 ZIP in **Plugins → Add New Plugin → Upload Plugin**.
2. Choose **Replace current with uploaded**.
3. Open **Ikon SEO → Technical Intelligence**.
4. Click **Refresh discovery and link graph**.
5. Run a small status-and-redirect batch.
6. Run a PageSpeed batch of one to three representative pages.
7. Re-import the focused schema in the private operator workspace.

Existing Website Profiles, Project History, connection keys, Search Console, Analytics and drafts remain in place.

The performance-data API key is optional. When configured, it is encrypted at rest and excluded from exports and REST reports.

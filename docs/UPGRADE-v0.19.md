# Upgrade to Ikon SEO v0.19.0

1. Back up the WordPress database and website files.
2. Upload the v0.19.0 ZIP and choose **Replace current with uploaded**.
3. Confirm your administrator under **Ikon SEO → Agency Access**.
4. Open **Ikon SEO → Visibility & Brand**.
5. If the database warning appears, deactivate and reactivate Ikon SEO once.
6. Configure the verified brand name, aliases and competitors.
7. Store one visibility observation and one external brand mention.
8. Refresh the combined snapshot.
9. Re-import the focused action schema.
10. Test the read command before storing evidence from the private workspace.

Existing Website Strategy, Search Console, Analytics, Publisher Intelligence, Local Growth, Authority Intelligence, Workflow Automation, Project History and Agency Command Centre data are preserved.

The focused schema remains at 30 operations. The Local NAP audit remains available in WordPress and the complete REST interface but is omitted from the focused schema to make room for Visibility & Brand Intelligence.

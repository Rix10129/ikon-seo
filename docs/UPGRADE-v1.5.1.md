# Upgrade to Ikon SEO v1.5.1

This hotfix repairs Agency Access initialization for a website with exactly one WordPress administrator.

## Install

1. Create a normal website backup.
2. Upload `ikon-seo-v1.5.1-hotfix.zip`.
3. Choose **Replace current with uploaded**.
4. Refresh **Ikon SEO**.
5. Confirm the additional agency tabs appear, including **Agency Access**.

## Data

- Database component remains `25.0`.
- Existing profiles, keys, integrations, history, plans, drafts and evidence are preserved.
- No public page is edited or published.

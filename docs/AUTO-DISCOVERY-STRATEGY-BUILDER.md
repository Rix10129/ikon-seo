# Auto Discovery & Strategy Builder

## Purpose

Auto Discovery reduces the manual setup required after installing Ikon SEO. It reviews the connected WordPress website and proposes a Website Profile and Website Strategy.

## Evidence reviewed

- WordPress site title, locale and public content
- Published pages, posts and products
- Visible contact links and forms
- WooCommerce, Elementor, Rank Math and Yoast signals
- Existing profile values
- Public same-site homepage HTML
- Available Search Console and Analytics connection status

## Confidence model

Each proposal records:

- Suggested value
- Confidence label and score
- Evidence sources
- Current value
- Whether business confirmation is required
- Whether the change may alter the profile identity

## Approval boundary

Auto Discovery does not automatically:

- Publish or edit pages
- Create redirects
- Change canonicals or noindex
- Change Business Profiles
- Request indexing
- Contact competitors
- Scrape search engines
- Invent prices, service areas, qualifications or guarantees

Only checked suggestions are applied by an approved Agency administrator.

## First-run workflow

1. Open **Ikon SEO → Auto Discovery**.
2. Review up to 50–100 public pages.
3. Resolve detected conflicts.
4. Accept high-confidence values.
5. Confirm offerings, audience, locations and positioning.
6. Apply selected suggestions.
7. Optionally create the recommended workflow.
8. Run one bounded read-only task.
9. Review Website Strategy and Website Profile.
10. Continue to Guided Launch, then generate the Operating Plan.

## Identity-sensitive fields

Changing the site name, industry or business entity type can change the Website Profile fingerprint. To prevent cross-client writes, Ikon SEO revokes the old workflow key when the identity changes. These fields are never preselected automatically.

## External research

The WordPress host performs local and same-site discovery. Current competitor and keyword research must come from Search Console, approved imports, stored competitor evidence, licensed providers or a separately configured private research workflow.

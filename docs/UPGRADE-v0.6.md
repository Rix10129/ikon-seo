# Upgrade to Ikon SEO v0.6

1. Back up WordPress and install the v0.6 ZIP over the existing plugin.
2. Open **Ikon SEO → Connection**.
3. The previous key remains available but is shown as **Waiting for pairing** until a valid authenticated request is received.
4. For the simpler flow, click **Reconnect Ikon SEO** and use the temporary pairing code.
5. Confirm the connection, scan the website and create one test draft.

The upgrade does not publish pages, merge review drafts or change the active Website Profile.

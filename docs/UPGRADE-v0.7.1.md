# Upgrade to Ikon SEO v0.7.1

This branding correction removes provider and generation terminology from the WordPress interface.

1. Upload the v0.7.1 ZIP and choose **Replace current with uploaded**.
2. Open **Ikon SEO → Overview**.
3. Continue with **Website Profile → Scan Website → Local SEO → Page Plans**.
4. Use **Workflow** only for a private operator connection.

No existing Website Profile, inventory, page plan or local SEO data is removed.

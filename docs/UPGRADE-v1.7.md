# Upgrade to Ikon SEO v1.7.0

## Before upgrading

1. Create a website and database backup.
2. Confirm Ikon SEO v1.6.0 is active.
3. Record the current Auto Discovery, Website Strategy and workflow status.

## Upgrade

1. Upload `ikon-seo-v1.7.0.zip`.
2. Choose **Replace current with uploaded**.
3. Open **Ikon SEO → Guided Launch**.
4. Confirm the existing Auto Discovery report is visible.
5. Review Website Strategy readiness and unresolved conflicts.
6. Run a maximum of three safe tasks during the first test.
7. Build the initial Operating Plan.
8. Confirm no public page, redirect, canonical, indexation setting or external profile changed.

## Data

No new database table is introduced. Existing settings, Website Profile, Auto Discovery evidence, workflows, Operating Plan, Project History, integrations, plans and drafts are preserved.

# Upgrade to Ikon SEO v0.14.0

1. Back up the WordPress database and files.
2. Upload the v0.14.0 ZIP and choose **Replace current with uploaded**.
3. Open **Ikon SEO → Website Strategy**.
4. Select the correct operating mode.
5. Complete the audience, value proposition, priority offers or topics, conversions and success metrics.
6. Add quality, evidence, authorship and approval policies.
7. Complete only the mode-specific section relevant to the website.
8. Review the Strategy Gaps table until readiness is at least developing.
9. Refresh Page Diagnostics so strategy-aware business values are recalculated.
10. Re-import the OpenAPI schema in the private workspace.

The existing workflow key, Project History, drafts and integrations remain intact. Strategy changes do not invalidate the website identity or connection key.

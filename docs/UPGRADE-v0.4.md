# Upgrade to Ikon SEO v0.4

1. Back up the WordPress database and files.
2. Upload `ikon-seo-v0.4.0.zip`.
3. Choose **Replace current with uploaded**.
4. Confirm the dashboard shows `0.4.0`.
5. Confirm the existing Website Profile, connection key, drafts, logs and reviews remain.
6. Open **Page Plans** and confirm the queue screen loads.
7. Open **Settings** and review the monitoring thresholds. Monitoring is disabled by default.
8. Connect Search Console only if you want read-only performance and indexing diagnostics.
9. Refresh the connected Action/OpenAPI schema so v0.4 operations become available.
10. Run the v0.4 smoke test before using the queue on client websites.

No new model API key is required. Search Console requires a Google OAuth client configured by the site administrator.

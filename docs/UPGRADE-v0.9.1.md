# Upgrade to Ikon SEO 0.9.1

1. Upload the 0.9.1 ZIP in **Plugins → Add New Plugin → Upload Plugin**.
2. Choose **Replace current with uploaded**.
3. Open **Ikon SEO → Page Diagnostics**.
4. Run an evidence crawl for stale pages.
5. Click **Refresh diagnoses**.
6. Review the new separate Work Priority, Ranking Priority, Evidence Sufficiency and Business Value fields.
7. Re-import the private workflow schema only when the action editor does not refresh it automatically.

Existing Website Profile, keys, Project History, Search Console and Analytics settings are preserved.

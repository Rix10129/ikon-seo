# Upgrade to Ikon SEO 0.10.0

1. Upload the 0.10.0 ZIP in **Plugins → Add New Plugin → Upload Plugin**.
2. Choose **Replace current with uploaded**.
3. Open **Ikon SEO → Search Intelligence**.
4. Confirm Search Console is connected and the correct property is selected.
5. Keep the first import at 28 days and 50,000 maximum rows unless the website is very large.
6. Click **Refresh Search Intelligence**.
7. Review overlap signals before merging, redirecting or rewriting any page.
8. Re-import the connected workflow schema only when the private workspace should read the new Search Intelligence action.

Existing profiles, project history, workflow keys, drafts, Analytics settings and diagnostics remain in place.

# Upgrade to Ikon SEO v1.6.0

## Before upgrading

1. Create a website and database backup.
2. Confirm v1.5.1 is active.
3. Record the current Website Profile and workflow connection status.

## Upgrade

1. Upload `ikon-seo-v1.6.0.zip`.
2. Choose **Replace current with uploaded**.
3. Open **Ikon SEO → Auto Discovery**.
4. Run a 25-page staging scan.
5. Confirm no public page changes.
6. Review suggested values before applying.
7. Leave identity-sensitive values unchecked during the first test.

## Data

No new database table is introduced. Database component version remains `25.0`. Existing settings, evidence, workflows, history, plans and drafts are preserved.

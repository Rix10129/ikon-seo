# Optional Workflow Connection

Ikon SEO works locally without any external workflow.

## Normal WordPress workflow

1. Complete the Website Profile.
2. Run the first Page Diagnostics evidence crawl.
3. Optionally connect Search Console and Analytics.
4. Review Site Inventory and Local SEO opportunities.
5. Prepare Page Plans.
6. Review and publish drafts manually.

## Private workflow access

A private operator workspace may be connected later to create structured review drafts. The setup uses the OpenAPI schema URL and a one-time workflow key under **Workflow → Workflow access settings**. Customers do not need to configure or view this area.

# Upgrade to Ikon SEO v0.7.2

1. Upload the v0.7.2 ZIP and choose **Replace current with uploaded**.
2. Open **Ikon SEO → Overview**.
3. Click **Scan Website**. No workflow connection or Google Business Profile is required.
4. Review **Local SEO** and **Page Plans**.
5. Open **Workflow** only when a compatible external workflow is already available.

Existing profiles, settings, local records, queues, logs and draft safeguards are preserved. Any current developer key remains available. The normal setup no longer asks non-technical users to create pairing codes.

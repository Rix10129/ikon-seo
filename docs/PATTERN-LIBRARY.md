# Portfolio Learning & Validated Pattern Library

Ikon SEO v1.13.0 turns human-acknowledged Search Impact studies into reusable, context-bounded learning patterns.

## Workflow

```text
Acknowledged impact study
→ Anonymised evidence record
→ Exact context signature
→ Candidate pattern
→ Cross-site consistency review
→ Human validation or limited-use decision
→ Advisory reference only
```

## Context signature

A pattern is grouped by:

- Website mode
- Industry
- Market
- Language
- Page type
- Change family
- Primary outcome metric

Evidence from a different context is not silently combined. Applying a validated pattern to a different context requires separate evidence and the normal Opportunity Engine, brief, editorial review and publishing readiness workflow.

## Validation threshold

Automated refresh can mark a pattern **Review ready**, but it cannot validate it. Human validation requires at least:

- Five usable medium/high-confidence directional studies
- Three distinct usable anonymised website fingerprints
- 65% directional consistency
- Medium or high aggregate confidence

A human approver can also mark a pattern **Limited use**, **Rejected** or **Retired**.

## Evidence changes

Each pattern stores an evidence fingerprint. When evidence changes after validation, the pattern becomes **Revalidation required** and its active approval is cleared. It must be reviewed again before being treated as validated.

## Privacy

Shareable evidence includes only:

- An irreversible website fingerprint
- A source study key
- Context categories
- Outcome and confidence labels
- Adjusted percentage movement
- Human decision
- Assessment hash and observation date

URLs, business names, page titles, queries, content, contact information and personal data are rejected from imported portfolio evidence.

## Interpretation

Patterns describe associated outcomes observed in a bounded context. They are not proof of causation, ranking guarantees, universal SEO rules or instructions to change a live website.

## Safety

The Pattern Library cannot publish, edit, merge, redirect, delete, noindex, change canonicals, submit URLs for indexing, update Google Business Profile, answer reviews or perform outreach/backlink actions.
